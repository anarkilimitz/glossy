# Фотографии портфолио

Эта папка предназначена для фотографий реальных работ по кузовному ремонту. Каждая работа находится в отдельной папке `repair-XX`.

- Фотографии **до ремонта** добавляйте в `repair-XX/before/`.
- Фотографии **после ремонта** добавляйте в `repair-XX/after/`.
- Рекомендуемый формат — `WebP` или `AVIF`.
- Рекомендуемый формат имени — `before.webp` и `after.webp` (или `before.avif` и `after.avif`), в нижнем регистре, без пробелов.

Чтобы подключить новую работу, создайте папку `repair-05` с подпапками `before/` и `after/`, добавьте в них соответствующие файлы, затем добавьте запись с `id`, названием, описанием и двумя путями в `src/shared/config/portfolio.ts`. Компонент `Portfolio` менять не требуется.

Пока реальные фотографии не добавлены, конфигурация использует временные пути к ожидаемым файлам. Фиктивные изображения в проект не добавляются.
