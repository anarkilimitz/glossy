# Фотографии автопарка

Папки `chery-arrizo-8`, `haval-f7`, `hyundai-solaris` и `volkswagen-polo` предназначены для фотографий соответствующих автомобилей. В каждую папку можно добавить один или несколько подготовленных кадров.

Рекомендуемые форматы — WebP или AVIF. Для карточек используется единое соотношение сторон 16:10; рекомендуемый размер — от 1280×800 px, чтобы изображение сохраняло качество на больших экранах.

Имена файлов должны быть строчными, без пробелов и кириллицы, с дефисами между словами: например, `car.webp` или `front-view.avif`.

Путь к основной фотографии указывается в `src/shared/config/fleet.ts` в поле `image` соответствующего автомобиля. До добавления реальных фотографий используются временные пути, а карточка показывает нейтральную заглушку при отсутствии файла.
